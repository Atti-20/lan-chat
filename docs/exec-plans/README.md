# 跨会话执行计划

任务超过一轮或包含多个独立验收项时，复制 [模板](template.md) 到 `active/<任务名>.md`。只记录目标、当前事实、下一步与证据，不复制聊天记录或令牌。

编号架构治理任务按用户指定的 `docs/tasks/active/MX-*.md` 保存唯一状态，复用本模板；不要在这里再复制同一计划。入口见 [任务索引](../tasks/README.md) 和 [协作流程](../ai/WORKFLOW.md)。

- 每轮结束更新已完成项、尚未完成项、涉及文件、已跑命令与失败边界。
- 新会话只读用户指定的活动计划和相关模块入口。
- 完成后移到 `completed/`；验收报告仍按根约定放 `docs/reports/`。
- 本目录没有活动实现任务时，不从 completed 或历史 TODO 自动推断要继续开发。

当前入口：[活动计划说明](active/README.md)、[完成计划说明](completed/README.md)。
