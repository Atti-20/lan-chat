## 保存约定

- 新报告按主题进入对应分类，并更新此索引；新主题可增加分类。
- README、开发规范等持续维护的说明文档不属于报告，无需附加报告日期。
- `reports/` 为本地报告归档，沿用 Git 忽略规则；截图、日志和安装包保留在原证据目录，报告内使用相对链接引用。
- 报告描述的是正文日期对应的状态；查看开发进度时同时参考更新日期更晚的报告与当前代码。
