# 产品范围

MeshX（代码/历史名称 LanChat）面向组织自有网络的沟通与协作，使用统一节点后端和多端客户端。

当前实现包含账号/设备、好友、私聊/群聊、文件、临时房间、应急广播与任务回执、管理/审计/诊断、节点发现，以及共享数据库的多实例实时路由。精确行为阅读对应代码和测试。

术语：

- 节点：提供 REST、WebSocket 与协作数据的逻辑服务；同节点的多个实例共享持久化依赖。
- 设备：用户的客户端登录/身份载体，不等同于服务节点。
- 会话：私聊、群聊或临时房间；消息具有会话内序列。
- Relay：经节点转发的数据路径；已有 WebRTC 文件直传及节点回退，不等于所有消息都已点对点化。

独立数据库节点双向同步、所有端后台可靠收信、正式 Harmony 客户端及各平台完整签名发布不能仅凭目录或构建存在宣称完成。长期目标与历史进度仍可在本地 PRD/TODO 查证；新的跨会话执行状态放 `docs/exec-plans`。

当前跨端实现与移动首发目标以 [v0.3.1功能矩阵](product-parity-matrix-v0.3.1.md)、[移动范围](mobile-release-scope-v0.3.1.md) 和 [Release Gates](mobile-release-gates-v0.3.1.md) 为准。矩阵区分Server/Web/Tauri/Flutter及验证层级；范围冻结不等于正式移动客户端已就绪。
