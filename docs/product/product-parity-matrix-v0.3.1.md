## 状态与阅读规则

| 状态 | 本矩阵含义 |
|---|---|
| IMPLEMENTED_VERIFIED | 行内明确的实现切片已有相关自动/运行证据；不代表全功能、全OS或Release Ready |
| IMPLEMENTED_PARTIAL | 该能力只接了一部分，或存在已知缺陷/明显语义缺口 |
| IMPLEMENTED_UNVERIFIED | 实际实现/调用存在，但没有足以覆盖本行行为的执行证据；仅有测试定义也归此类 |
| NOT_IMPLEMENTED | 未找到该端实际产品消费链；接口常量、DTO、占位文案不算实现 |
| BLOCKED | 验收所需硬件/环境不可用；本轮Android真机始终如此，不把代码本身改成未实现 |
| NOT_APPLICABLE | 该层没有相应职责，例如服务端的本地文件picker或客户端outbox |

Gate 分类与执行状态是另外两个维度：见 [Release Gates](mobile-release-gates-v0.3.1.md)，其中保留PASS/FAIL/BLOCKED/NOT_RUN原始结果。表内Tests表示证据覆盖，不是测试数越多越完整。所有A05/A06 PASS均为本轮重新读取的既有证据，A07A没有重跑业务/设备测试。

Desktop包含共享Vue UI及Tauri原生壳；`frontendDist=apps/web/dist-desktop`证明复用，不能证明macOS/Windows/Linux安装包同时通过。没有本轮桌面原生证据时保守标UNVERIFIED，继承的UI缺口标PARTIAL或NOT_IMPLEMENTED。浏览器不能直接做原生mDNS，服务端发现列表不等于浏览器扫描。

## 已确认缺口与架构判断

- **R01 生产LAN传输**：M02默认`allowLocalHttp=kDebugMode`，M01只允许正式HTTPS。S05的`secure`和公布端口来自部署配置；v2 `buildControlTxtProperties`未写`advertisedHost`，而旧TXT构造有此字段，客户端可能得到IP而非证书DNS名。这是源码确认的发布集成缺口，不是已经复现的TLS失败。A06独立Profile HTTP例外不关闭G11。
