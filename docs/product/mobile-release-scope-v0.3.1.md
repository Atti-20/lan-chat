# Mobile Release Scope v0.3.1

冻结日期：2026-09-09；范围负责人：MeshX 产品/仓库维护者；执行阶段：[MX-A07A](../tasks/active/MX-A07A.md)。本轮冻结首发目标，未宣布 Android 或 iOS Release Ready。功能当前状态以 [跨端矩阵](product-parity-matrix-v0.3.1.md) 为准；变更本范围须另记原因、影响、Gate 与验收，不把 A07B 的实现困难自动改写为延期。

## 产品与发行边界

保持 LAN-first、组织自有节点的沟通协作定位：Spring 为消息/权限事实来源，Web/桌面提供完整度更高的组织工作台，Flutter Android/iOS 承接日常沟通与移动接收/回执。不是做新的纯聊天产品，也不是把桌面所有管理页面搬进手机。

`v0.3.1` 是目标 Release Scope 标签。当前 Flutter 包仍为 `0.1.0+1` 和独立 prototype 标识；Tauri配置为0.3.0。A07A不修改这些值，不把原型直接称正式包。后续候选构建必须记录明确版本/build number、批准的应用身份、签名与分发渠道；选定渠道前不能宣称可分发。

移动首发的节点连接采用当前正式客户端的 HTTPS 验证规则。LAN 仍可离线于公网运行，但部署必须提供该设备信任且名称匹配的证书/端点。A06 的局部 HTTP 测试例外不进入产品。HTTP-only 节点、强制设备身份策略与 Flutter 的兼容范围必须在G11/G12验收和部署说明中明确；不得通过关TLS或降级节点策略实现“可用”。

## Deferred — P1 首发后近期

| 功能 | 延期原因与保留能力 |
|---|---|
| 移动自助注册、完善账号引导 | Web已经按节点策略提供，移动P0使用已有账号；不得强行要求开放注册 |
| 群改名/公告、成员编辑、转让/任免/禁言 | 服务端有接口，但Web也不完整；需要独立权限/事务验收，不伪称成熟桌面功能复制 |
| 临时房间创建/邀请码加入/离开 | Server/Web存在，Flutter当前不支持发送；首发界面明确不支持，不展示可发送假入口 |
| 登录设备列表/主动撤销、好友置顶/免扰/分组 | 既有Web个人设备功能可用；移动必须先正确接收撤销/会话失效，不依赖管理页 |
| 全分片续传、跨进程上传恢复、较大文件 | 当前Web/Server有实现；移动先保证有界基础文件完整发送和可重试 |
| 广播定位凭证、现场拍摄、复杂证据交互 | 需要新的真实权限/定位/相机验证；首发只办理无定位要求和已有文件图片凭证任务 |
| 主动高级消息功能、历史搜索、完整提及回执、深度无障碍增强 | 接收端一致性和基本辅助使用不能延期；发起侧增强可独立迭代 |

## Deferred — P2 后续

- 手机端广播创建、收件人编辑、提醒、统计/XLSX导出、管理员账号/RBAC/审计/运行日志控制台。现有Web/桌面继续保留；缺少的桌面群管理入口不能在帮助文案中伪装为可用。
- Flutter WebRTC/LAN文件直传；首发验证Web向Flutter发送时能通过现有节点回退完成，不需要先实现对等传输。
- APNs/FCM/OEM远程Push、跨节点复制/自动迁移、HarmonyOS。任何新的后台策略仍需系统合法能力与另行授权。

DEFERRED意味着不属于本版本承诺，不意味着可以删除已有Server/Web/桌面实现。依赖这些能力的组织场景需明示移动限制。

## Platform-specific Differences

| 平台 | 保留的差异 |
|---|---|
| Browser Web | 浏览器HTTP/Cookie与下载/Notification权限；没有客户端原生Bonjour。服务端发现列表与Tauri/手机本地扫描不同 |
| Tauri | 复用Vue UI，原生认证/网络、节点发现、保存文件、托盘/自启/窗口/更新独立；原生质量证据不继承Web测试 |
| Flutter Android | Kotlin NSD、Keystore、SAF content URI、原生通知/分享；运行时权限随API不同。真实设备/OEM未验收，后台不使用永久foreground service |
| Flutter iOS | Swift Bonjour、Keychain、security-scoped URL、UNUserNotificationCenter、UIActivityViewController；挂起后恢复SYNC，Settings按钮失败是真实缺陷 |
| 文件/通知共同边界 | 本地句柄不是可永久保存的系统路径；show成功是OS接受请求，分享面板成功不是对端已收到；按平台分别记录 |

## Blocked — 当前不能宣布就绪

- Android真实硬件不可用，保持 **BLOCKED**；模拟器通过不豁免G01。
- iPhoneSettings恢复入口 **FAIL**，缺经过接受的修复/完整手动fallback；通知横幅/点击、完整锁屏/换网、发布升级/旧OS/正式性能仍未验收。
- 全历史Gitleaks **FAIL**（本轮再次确认同一指纹），实际例外处置尚未授权执行；安全Gate不关闭。
- 远程CI、可复现候选构建、签名/分发、升级保留数据、受信HTTPS LAN和目标身份策略兼容没有完成证据。
- Flutter P0好友/群创建/附件/广播/资料尚缺代码。功能冻结不等于实现完成。

Android与iOS可以分别审查，但任何对应平台BLOCKING Gate未关闭都不能宣布该平台Release Ready。Android硬件缺失不阻止A07B编码，也不能让Android随iOS一起被宣称就绪。精确判据见 [Release Blocking Gates](mobile-release-gates-v0.3.1.md)。
