# Spring Boot 服务端范围规则（候选模板）

模板放置位置按本地源码组织确定；首期服务端仍为根 pom.xml + src/。
遵循根规则。版本、依赖以 pom.xml/Wrapper 为准，不自动升级到所谓最新版。
保留当前 API/WS 行为，重构与业务/数据库变更分别提交。
权限、群角色、文件可见性、用户/节点隔离由服务端强制执行。
新增/变更接口遵循已确定契约流程并验证旧客户端；不手改生成物。
OpenAPI 生成 SDK/DTO 不能替代服务端授权和集成测试。
已有数据库与 SQL 迁移策略先核对；不得通过清库或删数据解决测试。
日志脱敏，不输出 token、密码、完整私有消息或生产配置。

统一 server scope 要区分单元/契约/依赖外部服务的集成检查。
Maven 编译不代表端到端通过；缺少服务/凭据时记录具体阻塞。
Web 静态资源构建/打包链有变动时同时验证 Web 部署。
