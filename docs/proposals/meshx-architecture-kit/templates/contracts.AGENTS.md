# 契约范围规则（候选模板）

遵循根规则；修改前读 compatibility.md 和相关 ADR。
先确认本接口当前是 contract-first 还是只读 code-first 导出，不能维护两个编辑源。
不凭空重命名已有 v1 URL/字段/枚举/事件。破坏性变更须显式批准和迁移方案。
字段 optional/null、时间单位、序列安全范围、错误格式、事件方向都须明示。
共享模型在规范中只有一个源；镜像由生成链产生并检查一致。
生成器版本/配置固定；禁止手改生成 SDK、禁用 schema 检查或自动接受所有差异。

契约变化验证服务端、TS、Dart及所有实际消费者；OpenAPI 不覆盖 WS 状态机。
测试向量描述已确认的行为，不放真实用户数据，不从未知正确性的输出自动生成期望。
重新生成无 diff、契约校验和向后兼容测试是必要门禁；未运行项明确标记。
