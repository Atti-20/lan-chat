Feature Highlights

深入探索 MeshX 核心功能

事务级 ACK 与可靠消息机制

通过客户端在本地生成的唯一 clientMsgId，配合服务端的唯一联合索引 UNIQUE (from_user_id, client_msg_id)，彻底解决网络重试导致的消息重复问题。

  • 同一事务内分配会话 Sequence 并保存消息
  • 只有事务完全成功后才向客户端返回 CHAT_ACK
  • 重连后通过 SYNC_REQUEST 自动拉取遗漏缺口
// 可靠消息链路工作流
1. Local IndexedDB/SQLite
└─ Write message with clientMsgId, status="PENDING"
2. WebSocket CHAT_SEND
└─ Server verifies session permission & attachments
3. Database Transaction
└─ Assign sequence → Save Msg → Return CHAT_ACK
4. Delivery
└─ Move out of local Outbox → Deliver CHAT_DELIVER

2MB 窗口分片 SHA-256 断点续传

采用 2 MiB 滚动窗口计算文件完整 SHA-256，无需将 100MB 大文件一次性加载至内存。支持分片幂等重试、缺片查询与持久化对象清理重试队列。

  • 支持 LOCAL 私有目录与 MinIO S3 动态切换
  • 文件扩展名、MIME 与头部 Magic Bytes 三重校验
  • 10分钟临时签名预览地址与完整 file_access_log 审计
// REST Upload Protocol
POST /api/v1/file/uploads
└─ Return uploadId, totalParts, missingParts
PUT /api/v1/file/uploads/{id}/parts/{partNumber}
└─ Upload binary chunk with ?sha256=...
POST /api/v1/file/uploads/{id}/complete
└─ Re-verify total size & final SHA-256 checksum

多实例集群路由与全局 Presence

同一逻辑节点可无缝扩展多个 Spring Boot 实例。利用 Redis Pub/Sub 进行跨实例实时消息路由、设备下线与 WebRTC 信令转发，全局 Presence 带有自动续约与故障自愈机制。

  • 管理员实时连接诊断，探测 MySQL、Redis 延迟与 JVM 堆状态

Zero-Trust & Compliance

金融级安全与权限防护

HttpOnly Cookie 令牌轮换

Refresh Token 保存在 HttpOnly + SameSite=Strict Cookie 中，刷新时自动轮换；Access Token 仅短期保存在内存/sessionStorage，杜绝 XSS 泄露。

设备会话单活约束

数据库约束 UNIQUE (user_id, device_type)，同一账号同一设备类型单活登录，新登录自动吊销旧设备并发送 WebSocket 下线通知。

归档与独立物理擦除

支持用户非破坏性归档与匿名化。高风险数据物理擦除需独立二次审批流程，并写入不可篡改的 user_physical_erasure_audit 审计表。

Frequently Asked Questions

常见问题解答

MeshX 必须连接互联网才能使用吗？

完全不需要。MeshX 遵循纯粹的 LAN-First 设计原则，控制面与数据面均可在完全切断公网的纯局域网环境中流畅运行，依靠 DNS-SD / mDNS 自动发现节点与 P2P 直连。

如果 P2P 协商超时或失败会怎样？

MeshX 内置了无缝降级保护。WebRTC P2P 直连默认在 2 秒内尝试协商；如果协商失败、超时或处于跨网段复杂环境，系统会自动且透明地降级为由控制面（Spring Boot 服务器）进行安全中转或保存至离线信箱。

如何保证传输文件的安全性？

文件上传时会在服务端同时核对扩展名、MIME 类型和 Magic Bytes 文件头容器结构。文件存储支持 LOCAL 私有目录与 MinIO 私有 Bucket。生成的文件下载预览地址均为 10 分钟短时签名地址，每次访问均会重新复核会话权限，并记录完整审计日志。

什么是 AI Ops Agent 基础设施？

MeshX 为 Node Runtime 暴露了结构化工具接口（如查看节点健康度、网络延迟、结构化日志）。AI Agent 可以在得到管理员明确授权的前提下自然语言诊断并生成修复建议，任何具有副作用的操作均需经过确认与完整审计。
